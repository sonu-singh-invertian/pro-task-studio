# ProTask Studio

Official website of **ProTask Studio** - Your Academic & Task Partner.
Professional Resume | Content & Articles | Websites & College Projects.

Instagram: [@pro.task.studio](https://www.instagram.com/pro.task.studio/)

## Features
- Responsive dark-theme design (mobile + desktop)
- Services, how-it-works and FAQ sections
- Order booking form (sends order details to WhatsApp, optional Formspree email)
- No framework needed, a single `index.html`

## Setup
1. Open `index.html` and edit the `CONFIG` block near the bottom (WhatsApp number, email, Instagram link).
2. (Optional) Create a free form at [formspree.io](https://formspree.io), copy the endpoint and paste it in `CONFIG.formspree` to receive orders by email too.

## Deploy on GitHub Pages
1. Create a new repository (e.g. `protask-studio`) and upload `index.html` and `README.md`.
2. Go to **Settings -> Pages**.
3. Under **Source**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Your site will be live at `https://<your-username>.github.io/protask-studio/`.
